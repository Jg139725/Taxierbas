TAXI ERBAS – PAKET 13
EINZELFAHRT / MEHRPERSONENFAHRT
================================

NEU:
- Beim Erstellen einer Fahrt zuerst Auswahl:
  1. Einzelfahrt
  2. Mehrpersonenfahrt

EINZELFAHRT:
- ein Kunde
- ein Telefonkontakt
- ein Abholort
- ein Zielort
- nur EIN Fahrer-Auswahlfeld
- keine riesige Fahrer-Liste mehr

MEHRPERSONENFAHRT:
- beliebig viele Personen hinzufügen
- pro Person:
  Name
  Telefonnummer
  Abholort
  Zielort
- Personen können wieder entfernt werden
- mehrere Fahrer können über Auswahl + „Fahrer hinzufügen“ zugeordnet werden
- ausgewählte Fahrer erscheinen als kompakte Chips

WICHTIG – REIHENFOLGE:
1. Datei SUPABASE-Paket-13.sql öffnen.
2. Gesamten Inhalt in Supabase > SQL Editor > New Query kopieren.
3. Run klicken und auf Success prüfen.
4. Erst danach diese 3 Dateien in GitHub ersetzen:
   portal.html
   assets/css/portal.css
   assets/js/portal-live.js
5. GitHub Pages aktualisieren lassen.
6. Portal mit Cmd + Option + R neu laden.

VORHANDENE FAHRTEN:
Bestehende Fahrten bleiben erhalten und gelten automatisch als Einzelfahrten.

SONSTIGES:
Login, Kalender, Wiederholungsfahrten, Leitstelle und Fuhrpark werden nicht gelöscht.
