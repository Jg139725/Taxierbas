TAXI ERBAS – PAKET 11.3 DIALOG-FIX
===================================

Behoben:
- X schließt das Fenster wieder
- „Abbrechen“ schließt das Fenster, ohne Daten zu speichern
- Escape schließt das Fenster
- Klick auf den dunklen Hintergrund schließt das Fenster
- Lange Fenster bleiben scrollbar; Kopf und Schaltflächen bleiben erreichbar

INSTALLATION
------------
1. ZIP entpacken.
2. Alle Dateien in das GitHub-Repository „Taxierbas“ hochladen.
3. Vorhandene Dateien ersetzen.
4. GitHub Pages kurz aktualisieren lassen.
5. Portal neu laden. Bei Bedarf Safari-Cache mit Cmd + Option + R umgehen.
