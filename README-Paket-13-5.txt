TAXI ERBAS – PAKET 13.5
FAHRERANSICHT FIX
=================

Für Fahrer wurde geändert:

1. ÜBERSICHT
- nur eigene Fahrten von heute
- Fahrt anklickbar
- vollständige Details mit Kunde, Telefon, Route, Fahrzeug, Fahrtart, Hinweis
- Fahrt direkt bestätigen
- statt kompletter Flotte nur Fahrzeuge, die seinen heutigen Fahrten zugewiesen sind

2. FAHRTEN
- nur alle eigenen Fahrten des HEUTIGEN Tages
- Bestätigen
- Details ansehen
- nach Bestätigung Status auf Zugewiesen / Unterwegs / Abgeschlossen ändern

3. KALENDER
- Fahrer kann keine Fahrt hinzufügen
- Fahrer kann keine Fahrt bearbeiten
- Tag zeigt nur seine zugewiesenen Fahrten
- Bestätigen + Übersicht/Fahrtdetails

4. FUHRPARK
- Fahrer sieht nur Fahrzeuge, die seinen heutigen Fahrten zugeordnet sind

ADMIN / DISPOSITION
- bleiben unverändert und behalten ihre Bearbeitungsfunktionen.

INSTALLATION
1. portal.html in GitHub ersetzen
2. assets/js/portal-live.js ersetzen
3. assets/css/portal.css ersetzen
4. Kein weiterer Supabase-Code nötig, wenn Paket 13.4 bereits erfolgreich ausgeführt wurde.
5. Seite mit Cmd + Option + R neu laden.
