TAXI ERBAS – PAKET 13.6
NAVIGATION AB AKTUELLEM STANDORT
================================

NEU:
- Fahrer kann bei einer Fahrt direkt „Navigation starten“ drücken.
- Der Browser fragt beim ersten Mal nach Standortfreigabe.
- Danach öffnet sich Google Maps mit der Route:

  AKTUELLER STANDORT DES FAHRERS
  → ABHOLORT DER PERSON
  → ZIELORT

MEHRPERSONENFAHRT:
- Die eingetragenen Personen werden der Reihe nach als Stopps übernommen.
- Beispiel:
  aktueller Standort
  → Person 1 Abholung
  → Person 1 Ziel
  → Person 2 Abholung
  → Person 2 Ziel
  usw.

WO DIE NAVIGATION ERSCHEINT:
- vollständige Fahrtdetailansicht
- Fahrten-Seite als schneller „Route“-Button
- Kalender-Tagesansicht als „Route“-Button

WICHTIG:
- Beim ersten Start muss der Fahrer dem Browser Zugriff auf seinen Standort erlauben.
- Wird der Standort abgelehnt, kann Google Maps trotzdem geöffnet werden.
- Kein neuer Supabase-Code notwendig.

INSTALLATION:
1. portal.html in GitHub ersetzen
2. assets/js/portal-live.js ersetzen
3. assets/css/portal.css ersetzen
4. Seite mit Cmd + Option + R neu laden
