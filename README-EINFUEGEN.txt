- portal-sw.js

Enthaltene Änderungen:
- Adresse Bahnhofplatz 6
- Leistung 2 besser lesbar

- Kalender mit Tagesansicht

- mehrere Fahrer pro Fahrt
- Browser-Benachrichtigungen
- bestehende Leitstelle und Fuhrparkdarstellung

Installation:
1. ZIP entpacken.
2. Den Inhalt 1:1 in das GitHub-Repository Taxierbas hochladen.
3. Vorhandene gleichnamige Dateien ersetzen.
4. Supabase-Konfiguration und Logo-Dateien NICHT löschen; sie bleiben im Repository bestehen.
5. GitHub Pages aktualisieren lassen.
6. Browser vollständig neu laden.

WICHTIG:
Die Supabase-Erweiterung für ride_drivers, recurring_rides,
recurring_ride_drivers und recurring_exceptions muss separat im Supabase SQL Editor ausgeführt sein.
